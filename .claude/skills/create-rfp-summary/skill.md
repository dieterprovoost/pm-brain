---
name: create-rfp-summary
description: Summarize an RFP (Request For Proposal) document distilling all relevant input for a solution architect to be able to understand the request from the prospect fully. 
---

When in doubt, do not assume a certain interpretation but indicate in the summary you'll provide that you are in doubt and further validation is required. We are mainly looking on information about technical or architectural challenges the prospect is facing.

Only if an existing technical landscape is described, create a high-level diagram containing the mentioned pieces.

After summarizing the RFP document(s), end the summary with a what you believe are the main problems the prospect wants to solve.
